# Latency Logs Directory

This directory contains latency measurement logs for the AI receptionist webhook.

## File Structure

- `latency_logs.jsonl`: Line-delimited JSON file containing latency metrics for each webhook request

## Log Format

Each line is a JSON object with the following fields:

```json
{
  "timestamp": "2025-11-30T15:30:45.123Z",
  "ai_latency_ms": 456.78,
  "total_latency_ms": 523.45,
  "twilio_roundtrip_ms": 66.67,
  "input_token_count": 125,
  "output_token_count": 87,
  "model_name": "gemini-2.0-flash-exp"
}
```

## Field Definitions

- **timestamp**: UTC timestamp in ISO 8601 format
- **ai_latency_ms**: Time spent in AI generation (milliseconds)
- **total_latency_ms**: Total request latency from webhook start to response ready (milliseconds)
- **twilio_roundtrip_ms**: Twilio webhook overhead (total - AI latency, milliseconds)
- **input_token_count**: Number of input tokens sent to AI model
- **output_token_count**: Number of output tokens generated by AI model
- **model_name**: AI model identifier (e.g., "gemini-2.0-flash-exp")

## Latency Breakdown

```
total_latency_ms = twilio_roundtrip_ms + ai_latency_ms

Where:
- twilio_roundtrip_ms = network overhead + FastAPI processing + webhook overhead
- ai_latency_ms = actual time spent in Gemini API call
```

## Analysis

To analyze latency logs programmatically:

```python
from ai_receptionist.utils.latency_logger import analyze_latency_logs

# Analyze all logs
stats = analyze_latency_logs()
print(stats)

# Analyze last 100 requests
stats = analyze_latency_logs(last_n=100)
print(stats)
```

## Manual Analysis

Using command-line tools:

```bash
# Count total requests
wc -l data/latency_logs.jsonl

# View last 10 entries
tail -10 data/latency_logs.jsonl

# Calculate average AI latency
jq -s 'map(.ai_latency_ms) | add/length' data/latency_logs.jsonl

# Find requests with high latency (>1000ms)
jq 'select(.total_latency_ms > 1000)' data/latency_logs.jsonl

# Get P95 latency
jq -s 'map(.total_latency_ms) | sort | .[length*95/100|floor]' data/latency_logs.jsonl
```

## Monitoring Recommendations

1. **Alert thresholds:**
   - Warning: P95 total latency > 1000ms
   - Critical: P95 total latency > 2000ms

2. **Regular analysis:**
   - Daily: Check P95/P99 latency trends
   - Weekly: Compare token usage patterns
   - Monthly: Analyze model performance changes

3. **Optimization targets:**
   - AI latency: < 800ms (P95)
   - Total latency: < 1000ms (P95)
   - Twilio overhead: < 200ms (P95)

## Log Rotation

To prevent unbounded growth, consider implementing log rotation:

```bash
# Keep last 30 days of logs
find data -name "latency_logs.jsonl" -mtime +30 -delete

# Or compress old logs
gzip data/latency_logs.jsonl
mv data/latency_logs.jsonl.gz data/latency_logs_$(date +%Y%m%d).jsonl.gz
touch data/latency_logs.jsonl
```

## Privacy & Security
